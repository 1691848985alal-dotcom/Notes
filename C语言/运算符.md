# C 语言基础运算符速查笔记
### 1. 算术运算符：`+`、`-`、`*`、`/`、`%`
- **整除截断（`/`）**：两个整数相除会直接丢弃小数部分（如 `10 / 3` 结果为 `3`）。若需保留小数，除号两边至少要有一个浮点数（如 `5.0 / 2` 或 `(double)a / b`）。
- **取模求余（`%`）**：左右两边**必须都是整数**，不能用于浮点数（如 `10 % 3` 结果为 `1`）。
### 2. 赋值运算符：`=`、`+=`、`-=`、`*=`、`/=`、`%=`

将右侧的计算结果存入左侧变量中，复合赋值是简化写法：

| **复合写法**     | **等价展开**    | **示例（设 x = 5）** |
| ------------ | ----------- | --------------- |
| **`x += 3`** | `x = x + 3` | `8`             |
| **`x -= 2`** | `x = x - 2` | `3`             |
| **`x *= 4`** | `x = x * 4` | `20`            |
| **`x /= 2`** | `x = x / 2` | `2`             |
| **`x %= 3`** | `x = x % 3` | `2`             |
### 3. 关系运算符：`==`、`!=`、`>`、`<`、`>=`、`<=`

- **返回值**：成立（真）返回 **`1`**，不成立（假）返回 **`0`**。
- **核心防坑**：**`==`** 是判断左右是否相等，**`=`** 是赋值操作，切勿混用（如 `if (a == 5)` 不能写成 `if (a = 5)`）。
### 4. 自增与自减：`++`、`--`

用于让变量自身加 1 或减 1。单独成句时（如 `i++;` 和 `++i;`）效果完全一样；放进表达式赋值或传参时，遵循“谁在前面先干谁”：

| **类型**                 | **写法示例（设 a = 5）** | **记忆口诀**                                  | **执行后结果**        |
| ---------------------- | ----------------- | ----------------------------------------- | ---------------- |
| **前置** (`++a` / `--a`) | `b = ++a;`        | **先自增，后使用**（`a` 先变成 6，再赋给 `b`）            | `b = 6`, `a = 6` |
| **后置** (`a++` / `a--`) | `b = a++;`        | **先使用，后自增**（先把 `a` 的原值 5 赋给 `b`，`a` 再变 6） | `b = 5`, `a = 6` |

### 5. 运算符优先级（由高到低）
1. **括号 `()`**（最高，不确定顺序时直接加括号最稳妥）
2. **自增自减**：`++`、`--`
3. **乘除取模**：`*`、`/`、`%`
4. **加减**：`+`、 `-`  
5. **大小比较**：`<`、`>`、`<=`、`>=`
6. **相等判断**：`==`、`!=`
7. **赋值运算**：`=`、`+=`、`-=` 等（最低，算完右边所有式子最后才赋值）
