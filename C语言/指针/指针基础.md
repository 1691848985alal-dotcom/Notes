# 指针（基础）：概念、运算与数组

> 涵盖：什么是指针、指针运算、野指针、const 修饰、数组名、指针访问数组、数组传参、二级指针、指针数组 vs 数组指针、字符指针。
> 指针总览见 [[指针]]。

## 一、指针是什么
- 内存像一栋楼，地址就是门牌号。
- `&` 取地址，`*` 解引用。
- 指针类型决定两件事：**解引用读几个字节**、**±1 跳几个字节**（int* 跳 4，char* 跳 1）。

```c
int a = 10;
int* p = &a;          // p 存 a 的地址
printf("%d\n", *p);   // 10
```

## 二、指针运算
- `指针 ± 整数`：跳「一个元素」的大小，**不是 1 字节**。
- `指针 - 指针`：同一连续空间内，得到相隔的**元素个数**。
- 关系运算：同数组内可用 `>` `<` 比前后位置。
- ❌ 指针**不能相加、不能乘除**（无意义）。

```c
int arr[5] = {1,2,3,4,5};
int* p = arr;          // 指向 arr[0]
p + 1;                 // 指向 arr[1]，地址 +4
int* p1 = &arr[1], *p2 = &arr[4];
int n = p2 - p1;       // 3，相隔 3 个元素
```

## 三、野指针
成因：① 未初始化就使用 ② 越界访问 ③ 指向的空间释放后未置 NULL。
规避：定义即初始化（无指向设 `NULL`）、释放后置 `NULL`、使用前判非空、绝不过界。

## 四、const 修饰指针
**看 const 在 `*` 的左边还是右边：**
- `const` 在 `*` **左**：修饰内容（`*p` 不可改），指针本身可改。
- `const` 在 `*` **右**：修饰指针本身（`p` 不可改），内容可改。
- 两边都 const：都不可改。

```c
const int* p1 = &a;        // *p1 不能改，p1 能改
int* const p2 = &a;        // p2 不能改，*p2 能改
const int* const p3 = &a;  // 都不可改
```

## 五、数组名
绝大多数情况 = 首元素地址。**两个例外：**
- `sizeof(数组名)`：表示整个数组，算整体字节大小。
- `&数组名`：取整个数组的地址。
- `arr`、`&arr[0]`、`&arr` 三者**值相同、类型不同**，加步长后不同：

```c
int arr[5] = {0};
arr + 1;        // +4（跳一个 int）
&arr + 1;       // +20（跳整个数组），类型为 int(*)[5]
```

## 六、指针访问数组
- `p[i] == *(p + i)`，`arr[i] == *(arr + i)`
- `[]` 下标运算的本质：首地址 + 偏移量，再解引用。

## 七、数组传参本质
传参传的是首元素地址，故 `int arr[]` 与 `int* arr` **完全等价**，形参是**指针**。
→ 函数内 `sizeof(arr)` 是指针大小，无法求元素个数，需另传长度参数。
二维数组同理：其「首元素」是第一行（一维数组），指针形式 `int (*p)[5]`，第 i 行第 j 列 = `*(*(p + i) + j)`。

## 八、二级指针
指针变量也是变量，也有地址。存「指针变量地址」的，就是二级指针。

```c
int a = 10; int* p = &a; int** pp = &p;
*pp = &b;      // 等价于 p = &b
**pp = 30;     // 等价于 a = 30
```

## 九、指针数组 vs 数组指针
**靠运算符优先级区分：**
- `int* p1[10];` → 指针数组：`[]` 优先，p1 是数组，元素是 `int*`。
- `int (*p2)[10];` → 数组指针：括号让 `*` 先结合，p2 是指针，指向 `int[10]`。

## 十、字符指针
指向字符串字面量时，存的是**首字符地址**（不是整个串）。
- 两数组用同一字面量初始化 → 开辟**两块不同内存**。
- 两指针指向同一字面量 → 指向**同一块内存**。

```c
const char* pstr = "hello";   // 存的是 'h' 的地址
```
