# C 语言指针精简笔记

> **核心一句话：指针就是内存地址。**
> 所有花样都围绕两件事展开——「地址指向什么类型」和「±1 怎么跳」。

## 知识链条（先建立全局观）
数组名是地址 → 传参传的是地址 → 数组指针指向一行 → 函数指针指向函数 → 函数指针数组组成转移表 → 回调函数把函数指针当参数 → qsort 用 void* 做到通用。
把这根链条理清，指针就不再可怕。

## 一、指针是什么
- 内存像一栋楼，地址就是门牌号。
- `&` 取地址，`*` 解引用。
- 指针类型决定两件事：**解引用读几个字节**、**±1 跳几个字节**（int* 跳 4，char* 跳 1）。

```c
int a = 10;
int* p = &a;          // p 存 a 的地址
printf("%d\n", *p);   // 10
```

## 二、指针运算
- `指针 ± 整数`：跳「一个元素」的大小，**不是 1 字节**。
- `指针 - 指针`：同一连续空间内，得到相隔的**元素个数**。
- 关系运算：同数组内可用 `>` `<` 比前后位置。
- ❌ 指针**不能相加、不能乘除**（无意义）。

```c
int arr[5] = {1,2,3,4,5};
int* p = arr;          // 指向 arr[0]
p + 1;                 // 指向 arr[1]，地址 +4
int* p1 = &arr[1], *p2 = &arr[4];
int n = p2 - p1;       // 3，相隔 3 个元素
```

## 三、野指针
成因：① 未初始化就使用 ② 越界访问 ③ 指向的空间释放后未置 NULL。
规避：定义即初始化（无指向设 `NULL`）、释放后置 `NULL`、使用前判非空、绝不过界。

## 四、const 修饰指针
**看 const 在 `*` 的左边还是右边：**
- `const` 在 `*` **左**：修饰内容（`*p` 不可改），指针本身可改。
- `const` 在 `*` **右**：修饰指针本身（`p` 不可改），内容可改。
- 两边都 const：都不可改。

```c
const int* p1 = &a;        // *p1 不能改，p1 能改
int* const p2 = &a;        // p2 不能改，*p2 能改
const int* const p3 = &a;  // 都不可改
```

## 五、数组名
绝大多数情况 = 首元素地址。**两个例外：**
- `sizeof(数组名)`：表示整个数组，算整体字节大小。
- `&数组名`：取整个数组的地址。
- `arr`、`&arr[0]`、`&arr` 三者**值相同、类型不同**，加步长后不同：

```c
int arr[5] = {0};
arr + 1;        // +4（跳一个 int）
&arr + 1;       // +20（跳整个数组），类型为 int(*)[5]
```

## 六、指针访问数组
- `p[i] == *(p + i)`，`arr[i] == *(arr + i)`
- `[]` 下标运算的本质：首地址 + 偏移量，再解引用。

## 七、数组传参本质
传参传的是首元素地址，故 `int arr[]` 与 `int* arr` **完全等价**，形参是**指针**。
→ 函数内 `sizeof(arr)` 是指针大小，无法求元素个数，需另传长度参数。
二维数组同理：其「首元素」是第一行（一维数组），指针形式 `int (*p)[5]`，第 i 行第 j 列 = `*(*(p + i) + j)`。

## 八、二级指针
指针变量也是变量，也有地址。存「指针变量地址」的，就是二级指针。

```c
int a = 10; int* p = &a; int** pp = &p;
*pp = &b;      // 等价于 p = &b
**pp = 30;     // 等价于 a = 30
```

## 九、指针数组 vs 数组指针
**靠运算符优先级区分：**
- `int* p1[10];` → 指针数组：`[]` 优先，p1 是数组，元素是 `int*`。
- `int (*p2)[10];` → 数组指针：括号让 `*` 先结合，p2 是指针，指向 `int[10]`。

## 十、字符指针
指向字符串字面量时，存的是**首字符地址**（不是整个串）。
- 两数组用同一字面量初始化 → 开辟**两块不同内存**。
- 两指针指向同一字面量 → 指向**同一块内存**。

```c
const char* pstr = "hello";   // 存的是 'h' 的地址
```

## 十一、函数指针
函数名就是函数地址，存函数地址的变量是函数指针。

```c
int add(int x, int y) { return x + y; }
int (*pf)(int, int) = add;
printf("%d\n", pf(2, 3));    // 通过函数指针调用
```
注意：`*` 和变量名必须用括号包起来，否则成了「返回指针的函数」。

## 十二、函数指针数组
把多个函数地址存进数组——元素类型是 `int(*)(int,int)`。

```c
int (*parr[3])(int, int) = { add, sub, mul };
parr[0](10, 5);    // 调用 add
```

## 十三、转移表
函数指针数组的典型应用：用下标直接「跳」到对应函数，替代又长又重复的 switch（计算器示例）。

```c
int (*p[5])(int, int) = { 0, add, sub, mul, div };
ret = (*p[input])(x, y);   // 用 input 当下标直接跳转
```

## 十四、回调函数
把函数指针当参数传给另一个函数，那个「被调用的函数」就是回调函数。
价值在**解耦**——调用方不用知道具体调的是谁。典型代表是 `qsort`。

## 十五、qsort 使用
```c
void qsort(void *base, size_t nmemb, size_t size,
           int (*compar)(const void *, const void *));
```
- `base` 待排序首地址；`nmemb` 元素个数；`size` 单元素字节；`compar` 比较函数指针。排序直接作用于原数组。
- 比较函数：返回**负数** → p1 在前；**正数** → p2 在前；**0** → 相等。
- int 升序：`return *(int*)p1 - *(int*)p2;`；降序反过来写。
- ⚠️ 浮点/结构体**不要直接相减**（小数被截断成 0），用分支返回 1 / -1 / 0。

```c
int int_cmp(const void* p1, const void* p2) {
    return *(int*)p1 - *(int*)p2;
}
int arr[] = {1,3,5,7,9,2,4,6,8,0};
qsort(arr, sizeof(arr)/sizeof(arr[0]), sizeof(int), int_cmp);
```

## 十六、qsort 模拟实现（重点）
通用三要素：`void* base`（不假设类型）+ `size`（每个元素几字节）+ 比较函数指针（比较交给使用者）。
- `void*` 能接收任何地址，但**不能直接解引用/加减**，需先强转。
- 定位第 j 个元素：`(char*)base + j*size`（char 恰好 1 字节）。
- 交换任意类型：逐字节交换 `size` 次。

```c
void _swap(void* p1, void* p2, int size) {
    for (int i = 0; i < size; i++) {
        char tmp = *((char*)p1 + i);
        *((char*)p1 + i) = *((char*)p2 + i);
        *((char*)p2 + i) = tmp;
    }
}
void bubble(void* base, int count, int size,
            int (*cmp)(const void*, const void*)) {
    for (int i = 0; i < count - 1; i++)
        for (int j = 0; j < count - i - 1; j++)
            if (cmp((char*)base + j*size, (char*)base + (j+1)*size) > 0)
                _swap((char*)base + j*size, (char*)base + (j+1)*size, size);
}
```
