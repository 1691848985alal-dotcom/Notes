# 题目案例 · 索引

> 存放 C 语言练习 / 题目案例的地方。本文件夹会越存越多，靠 **统一命名 + 标签 + 模板** 保持不乱——不需要手动维护一份长列表。

## 约定（每篇都照做，就不会乱）

1. **命名**：`题目案例/<简短主题>.md`，用中文短名（如 `n项求和.md`、`水仙花数.md`、`冒泡排序.md`）。
   - ❌ 不要加日期前缀、不要写“关于/练习”这类词，名字就是主题本身。
2. **标签（必填，这是归类的核心）**：
   - `题目案例` —— 每篇都打，所有案例统一归入这一个标签。
   - `分类/xxx` —— 按知识点分，用 Obsidian 的嵌套标签，例如：
     `分类/数学计算` · `分类/数组` · `分类/字符串` · `分类/指针` · `分类/递归` · `分类/排序查找` · `分类/结构体` · `分类/文件IO` · `分类/综合`
   - 可选：`难度`（⭐ ～ ⭐⭐⭐）。
3. **结构**：直接复制 `[[题目案例/模板]]`，保持「题目 / 思路 / 代码 / 笔记 / 配图」五段式，每篇长得一样才好扫。
4. **配图**：截图统一进 `题目案例/附件/`，Obsidian 按文件名全局引用，无需改路径。

## 怎么找（不靠翻文件列表）
- 左侧 **标签** 面板：点 `题目案例` 看全部，点 `分类/数学计算` 等只看某一类——数量再多也瞬间筛出。
- 搜索：`tag:题目案例` 或 `路径:题目案例`。
