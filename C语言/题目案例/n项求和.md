# n 项求和

## 题目
计算 $1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n}$ 这类连续分式求和；以及 $1 + \frac{1}{2} - \frac{1}{3} + \dots - \frac{1}{n}$ 这种正负交替的变体。

## 配图
![[n项和.png|393]]
![[n项加减.png|404]]

## 思路与笔记
- 用 `for` 循环，条件 `i <= n` 即可累计 n 项。
- 用 `double` 是因为结果是分数；`a += 1.0 / i` 中只要有一边是分数，结果才会是分数。
- 正负交替变体：把 `1.0` 换成一个变量，每轮循环给它一个负号（负负得正、正负为负）即可。
